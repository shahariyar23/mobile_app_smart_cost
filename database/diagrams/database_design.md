# Database Design

This directory contains the Smart Cost database design artifacts.

- `erd.png` - ERD image placeholder.
- `erd.drawio` - Draw.io source for the entity relationship diagram.
- `database_design.md` - Notes and design decisions.

## Design overview

The database stores user accounts, transaction categories, financial transactions, budgets, goals, notifications, voice command logs, and AI-generated insights.

Tables:
- `users`
- `categories`
- `transactions`
- `budgets`
- `goals`
- `notifications`
- `voice_logs`
- `ai_insights`
